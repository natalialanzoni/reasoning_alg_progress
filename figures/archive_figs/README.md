## The two live figure directories

- **`paper_figs/`** — the curated set. If it is not in there, it is not in the paper.
  Built by `code/make_paper_figs.sh`, which also writes `paper_figs/MANIFEST.md`.
- **`figs_sept/`** — the working directory. Everything the live scripts emit, including
  sensitivity variants that are deliberately not in the paper (`_alltraces`,
  `_no_o1`, `_fulldiff`, `fig4_forecast_combined`, `fig2_hard_distributions`). Those
  are current and reproducible; they are simply not cited.
